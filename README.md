# Week 9 – Statistics for Data Analytics

This project demonstrates the application of core statistical concepts using Python on a real-world sales dataset.

## Key Concepts Covered
- Population and Sampling
- Random and Systematic Sampling
- Central Limit Theorem (CLT)
- Normal Distribution
- 68–95–99.7 Rule
- Z-Score and Outlier Detection

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
Superstore Sales Dataset
